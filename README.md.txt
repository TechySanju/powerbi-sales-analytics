# Power BI Sales Analytics Dashboard

Author: Sanju Singh

## Project Overview
This project is an interactive Power BI dashboard built to analyze sales performance.
It helps understand revenue trends, market distribution, and top products and customers.

## Tools Used
- Power BI Desktop
- Power Query
- DAX
- GitHub

## Dataset
The project uses a sales database.
Only a small anonymized sample dataset is shared in this repository for safety.

## Key Features
- Revenue and Sales Quantity KPIs
- Market-wise sales analysis
- Top customers and products
- Time-based analysis using date table
- Cleaned and transformed data using Power Query

## Files in this Repository
- pbix/Sales.pbix : Power BI dashboard file
- data/transactions_sample.csv : Sample dataset
- exports/Sales_Dashboard.pdf : Exported dashboard
- exports/Dashboard_Overview.png : Dashboard screenshot
- exports/Dashboard_Model.png : Data model screenshot

## How to Use
1. Download the Sales.pbix file
2. Open it using Power BI Desktop
3. Load your own dataset or review the visuals
